# Kolekcjoner

## Opis projektu

Kolekcjoner to prosta gra ekonomiczna stworzona w języku C# z wykorzystaniem technologii WPF. Celem gry jest zarabianie pieniędzy, kupowanie ulepszeń i rozwijanie własnej firmy.

## Technologie

- C#
- .NET
- WPF (Windows Presentation Foundation)
- XAML
- Visual Studio

## Funkcje

- Zarabianie pieniędzy poprzez klikanie przycisku PRACUJ.
- Ulepszanie zarobków za kliknięcie.
- Zwiększanie wydajności pracy.
- Automatyczne zarabianie pieniędzy co sekundę.
- Rozwijanie firmy i zwiększanie dochodów pasywnych.
- Dynamiczne aktualizowanie salda i poziomów ulepszeń.
- Sprawdzanie, czy gracz ma wystarczającą ilość pieniędzy.
- Możliwość zresetowania gry.
- Ciemny interfejs z elementami w kolorze złotym i zielonym.

## Dostępne ulepszenia

| Ulepszenie | Koszt początkowy | Efekt |
|---|---:|---|
| Lepsza praca | 25 zł | +1 zł za kliknięcie |
| Wydajność | 100 zł | +5 zł za kliknięcie |
| Automatyczna praca | 150 zł | +1 zł na sekundę |
| Rozwój firmy | 300 zł | +5 zł na sekundę |

Koszt ulepszeń wzrasta po każdym zakupie.

## Uruchomienie projektu

1. Otwórz plik poradnik.slnx w Visual Studio.
2. Poczekaj na załadowanie projektu.
3. Uruchom aplikację klawiszem F5.
4. Klikaj przycisk PRACUJ, aby zdobywać pieniądze.
5. Kupuj ulepszenia, aby zwiększać swoje dochody.

## Struktura projektu

- MainWindow.xaml – interfejs graficzny aplikacji.
- MainWindow.xaml.cs – logika gry, obsługa przycisków i system ulepszeń.
- poradnik.slnx – plik rozwiązania Visual Studio.
